# Conflux protocol v1

The source of truth is `internal/protocol`. QUIC ALPN is `conflux/1`; TLS verification remains enabled and enrollment supplies an explicit certificate trust anchor plus SHA-256 certificate pin. QUIC DATAGRAM capability is mandatory. A reliable bidirectional control stream performs attachment before data transmission. There is no extra home-grown encryption layer.

Control messages are a four-byte unsigned big-endian JSON byte length followed by UTF-8 JSON, with a maximum of 4096 bytes. Unknown fields and trailing data are rejected. The client Hello contains `version`, `session`, `instance`, `path`, `token`, `mtu`, `datagrams`. Session and instance identifiers encode 16 random bytes as hexadecimal. Path IDs are 1–64 bytes; tokens are 1–256 bytes. The codec accepts requested MTU 576–1280; current relay configuration caps negotiation at 1100. At most 16 path identities attach to a session. The relay Welcome contains `version`, `ip`, `mtu`, and optional sanitized `error`. It authenticates the token and attaches independent paths to the same authorized session. The control stream remains open. Final shutdown sends `{"type":"close-session"}` and receives `{"type":"closed"}` to release session state immediately; unclean disconnect leaves a 60-second lease. A version mismatch fails explicitly; v1 does not promise compatibility with future incompatible versions.

| Datagram offset | Bytes | Meaning |
|---|---|---|
| 0 | 1 | Version = 1 |
| 1 | 1 | Kind: 0 = IPv4 data, 1 = ping, 2 = pong |
| 2 | 2 | Reserved; must be zero |
| 4 | 8 | Big-endian sequence; nonzero |
| 12 | 2 | Big-endian payload length |
| 14 | length | Payload; at most 1280 bytes |

Ping/pong payloads are empty. Decode borrows the input buffer and performs bounded length checks before exposing payload. IPv4 validation checks version, header length and total length; IPv6 is unsupported. Unknown kind, version, reserved bits, zero sequence or inconsistent lengths is invalid. Transport authentication and replay protection are supplied by QUIC. Application-level reorder rejects stale/duplicate packets within its bounded window; it does not retry indefinitely for gaps.

The negotiated implementation maximum and default tunnel MTU are 1100 bytes to leave space for transport overhead; the codec itself accepts at most 1280. Negotiation must use the lower accepted MTU. No custom IP fragmentation is promised; oversized inner packets must be rejected or handled by the operating-system path-MTU behavior. Maximum codec size is a bound, not proof a given proxy can carry that size.

Enrollment uses `conflux://HOST:4433?fp=HEX&cert=BASE64URL_DER&token=SECRET`. Treat the complete string as a credential. The certificate is both explicitly trusted and pinned; clients must still check its validity, server name and TLS chain against that configured anchor. Never turn off normal TLS verification. Enrollment is generated by `conflux-relay --init HOST --config PATH` and printed only at creation. Do not paste it into issue reports, logs, shell history or benchmark arguments.

Malformed control/auth/session/capability errors must be sanitized. Authentication failure does not allocate an unlimited session or reveal whether another session exists. Exact error wording is not a stable API. Any protocol expansion must preserve explicit bounds, negotiate version/capability and add malformed-input/fuzz tests.

Current transport bounds are 128 queued sends per path and 512 received packets per endpoint. Reorder holds at most 512 packets / 655360 bytes for 8 ms, rejects a sequence jump above 65536, drops late/duplicate packets and releases expired gaps. Ping interval is 250 ms; two pong replies establish healthy status, while two seconds without pong triggers reconnection. Retry begins at 100 ms, doubles up to five seconds with 0–33% cryptographic jitter and has a 30-attempt budget, reset after 30 seconds stable. These are implementation policy values, not wire compatibility promises; changes require regression tests and live performance review.
