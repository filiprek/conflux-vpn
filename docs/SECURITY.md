# Security design and operational limits

The relay is authenticated with normal QUIC/TLS verification plus a SHA-256 certificate pin from enrollment. Generated enrollment includes the self-signed certificate as an explicit trust anchor, allowing hostname and certificate verification without a public CA. Protect the enrollment exchange through an independent trusted channel and compare its fingerprint out of band. Certificate expiry, host mismatch and pin mismatch must fail closed. Token rotation requires replacing the relay token and re-enrolling clients; there is no public token recovery API.

Windows configuration separates non-secret `config.json`, DPAPI-protected `secrets.dat` and owned network recovery state. The installer confines data to SYSTEM and administrators and gives normal users read/execute access to program binaries. The service owns decryption. The pipe is `Conflux-<owner SID>` with ACL access for that user, SYSTEM and administrators. A local administrator, compromised service or kernel can access secrets and alter networking; protection from these principals is outside scope.

sing-box is supplied separately at an explicit absolute path, pinned by SHA-256 and expected version. Generated runtime configuration necessarily contains proxy credentials and must have restrictive permissions and bounded retention. Do not accept executable directives, external config references or plugins from imported links. No runtime downloader is included. Wintun is operator-supplied and requires trusted hash provenance and a valid official signature. There is no code-signing certificate for the project installer; it is explicitly unsigned.

Route/DNS/IPv6 state is recorded before mutation and restored only with ownership evidence. Windows keeps physical DNS settings unchanged, configures `1.1.1.1` on the TUN with a pinned resolver route, limits ordinary DNS port 53 to that resolver and blocks IPv6 globally while active. Owned rules and routes are removed on disconnect; no privacy claim is made about the resolver operator. Do not disable IPv6 permanently or reset the Windows network stack. The Linux installer owns only `ip conflux`, `conflux0`, its service files and recorded forwarding changes. Other firewall chains can still block forwarding; inspect policy rather than replacing it globally. Network rollback failure must be surfaced and preserve the journal.

Logs and diagnostics must redact tokens, UUIDs, complete VLESS links, REALITY values and passwords. Review exported local bundles before sharing: even redacted operational data can expose hostnames, IPs and timing. This project contains no analytics, advertising, remote crash upload or telemetry upload. Ordinary VPN/proxy/relay traffic is necessary network activity, and diagnostics are shared only by an operator.

No security audit, anonymity guarantee, censorship guarantee or complete leak-proof acceptance is claimed. See [ACCEPTANCE.md](ACCEPTANCE.md), [THREAT_MODEL.md](THREAT_MODEL.md) and [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md). Dependency scans and license audits must be reviewed for each release, including transitive modules and the actual supplied runtime binaries.
