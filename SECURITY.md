# Security policy

This repository is pre-release. No supported release or security maintenance window is declared. Do not use it for safety-critical traffic until the acceptance matrix has passed on real target systems.

Report a vulnerability through the repository's private GitHub vulnerability reporting facility if enabled. If unavailable, ask a maintainer for a private channel without posting exploit details or credentials publicly. Never attach a relay enrollment string, VLESS URI, unredacted configuration or decrypted storage. Share the commit, affected component, platform and a sanitized reproduction.

See [security architecture](docs/SECURITY.md), [threat model](docs/THREAT_MODEL.md), [dependency notices](THIRD_PARTY_NOTICES.md) and [acceptance status](docs/ACCEPTANCE.md). No code-signing identity or audited security certification is claimed.
